Como instalo no Android?+

Baixe o APK pelo botão acima e abra o arquivo no celular. Se o Android solicitar, permita a instalação pelo aplicativo que abriu o arquivo. Depois, abra o Corre Nengue e toque em Nengue Play.

O que preciso para jogar?+

Um celular com Android 5.0 ou superior. Esta versão é distribuída como APK para instalação direta. O download tem aproximadamente 18,6 MB.

Como funcionam os bônus?+

Colete os itens no vão das paredes. A banana ativa Sayajin, o celular amplia a passagem e a bazuca dispara contra as paredes. Cada efeito dura 10 segundos de jogo ativo; a pausa congela o tempo.

Onde encontro o projeto?+

O código do jogo está no repositório Corre Nengue no GitHub. Esta página de apresentação faz parte do mesmo projeto.
