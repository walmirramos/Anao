# Publicação do Corre Nengue

- Endereço: https://walmirramos.github.io/FlappyNengue/
- Hospedagem: GitHub Pages, com acesso público.
- Repositório: https://github.com/walmirramos/FlappyNengue
- Branch: `main`.
- Diretório publicado: `/docs`.
- Tipo de publicação: Pages por branch (`legacy`), com `.nojekyll`.

Os links são relativos para funcionar em `/FlappyNengue/`. Os recursos, o APK
1.10.1 e seu SHA-256 estão no mesmo repositório, dentro de `docs`.

Um novo commit na pasta `docs` atualiza o site pelo GitHub Pages. Nenhum domínio
personalizado foi registrado ou conectado. A publicação anterior no Sites pode
continuar existindo, mas o endereço principal desta apresentação é o GitHub Pages.
